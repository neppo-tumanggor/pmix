# API Design

Rancang API berdasarkan existing architecture, domain model, consumer requirements, dan convention yang digunakan project.

Prioritaskan contract yang jelas, predictable behavior, compatibility, dan minimal breaking changes.

## Usage

Gunakan skill ini ketika membuat atau mengubah REST API, GraphQL, RPC, webhook, internal service API, endpoint, request, response, error model, atau public contract.

## Steps

1. Analisis existing API contract, consumers, domain model, authentication, authorization, validation, error handling, dan compatibility requirements.
2. Rancang atau ubah API dengan contract yang konsisten, input validation yang jelas, predictable errors, appropriate idempotency, dan minimal breaking changes.
3. Verifikasi implementation terhadap contract, tests, security requirements, edge cases, dan backward compatibility sebelum perubahan dianggap selesai.
