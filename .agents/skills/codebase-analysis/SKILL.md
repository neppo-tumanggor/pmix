# Codebase Analysis

Bangun pemahaman yang cukup terhadap codebase sebelum melakukan implementation atau perubahan yang memiliki impact signifikan.

Gunakan evidence dari repository dan hindari asumsi terhadap architecture atau behavior yang belum diverifikasi.

## Usage

Gunakan skill ini ketika mengerjakan codebase yang belum dipahami, mencari lokasi implementation, menganalisis dependency atau data flow, merencanakan perubahan lintas component, atau menentukan impact dari perubahan yang akan dilakukan.

## Steps

1. Analisis struktur repository, technology stack, entry points, configuration, existing documentation, dan development conventions yang relevan.
2. Trace component, dependency, interface, data flow, dan execution path yang berkaitan dengan task untuk memahami current implementation dan affected area.
3. Identifikasi file yang perlu diubah, dependency dan potential impact, existing pattern yang harus diikuti, serta risiko perubahan sebelum implementation dimulai.
