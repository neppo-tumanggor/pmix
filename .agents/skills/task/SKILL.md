# Task

Ubah request menjadi task yang jelas, terukur, dan dapat dieksekusi sebelum melakukan perubahan codebase.

Jaga scope tetap sesuai tujuan user dan gunakan engineering orchestration serta skill yang relevan selama execution.

## Usage

Gunakan skill ini ketika menerima feature request, bug fix, refactoring, technical change, atau engineering task yang membutuhkan analisis, planning, implementation, dan validation.

## Steps

1. Pahami objective, requirements, constraints, affected area, acceptance criteria, dan informasi yang masih perlu diverifikasi dari codebase.
2. Susun execution plan dengan scope minimal, tentukan skill yang relevan berdasarkan engineering orchestration, lalu jalankan pekerjaan secara terurut dan adaptif terhadap temuan selama implementation.
3. Verifikasi acceptance criteria, tests, review, documentation, final diff, dan quality gates yang relevan sebelum menyatakan task selesai.
