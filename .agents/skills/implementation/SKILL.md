# Implementation

Implementasikan perubahan dengan scope minimal yang memenuhi requirement dan mengikuti existing architecture, pattern, convention, serta tooling project.

Prioritaskan correctness, simplicity, maintainability, dan consistency. Hindari unrelated changes, speculative abstraction, dan unnecessary complexity.

## Usage

Gunakan skill ini ketika membuat feature, menambah atau mengubah behavior, mengimplementasikan requirement, atau melakukan perubahan production code yang bukan sekadar debugging atau refactoring.

## Steps

1. Pahami requirement, affected area, existing implementation, dependencies, constraints, dan acceptance criteria sebelum mengubah code.
2. Implementasikan perubahan secara incremental dengan mengikuti existing pattern dan menjaga compatibility, error handling, edge cases, serta scope tetap minimal.
3. Verifikasi implementation terhadap requirement dan affected behavior, lalu teruskan ke testing, review, documentation, dan validation yang relevan sebelum task dianggap selesai.
