# Performance

Lakukan performance optimization berdasarkan evidence, profiling, benchmark, dan measurable bottleneck.

Hindari premature optimization dan perubahan kompleks tanpa improvement yang dapat diverifikasi.

## Usage

Gunakan skill ini ketika terjadi latency, slow query, high CPU atau memory usage, excessive I/O, network overhead, concurrency issue, inefficient algorithm, scalability problem, atau kebutuhan performance optimization lainnya.

## Steps

1. Ukur current performance, tetapkan baseline, dan gunakan profiling atau observability data untuk mengidentifikasi bottleneck serta root cause.
2. Terapkan optimization dengan scope minimal pada bottleneck yang terbukti tanpa mengubah correctness, contract, atau behavior yang tidak terkait.
3. Jalankan benchmark, tests, dan validation setelah perubahan, bandingkan dengan baseline, dan pastikan improvement terukur tanpa regression.
