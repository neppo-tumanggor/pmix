# Observability

Implementasikan observability berdasarkan operational needs dan existing infrastructure project.

Prioritaskan telemetry yang actionable, terstruktur, dan memiliki context yang cukup tanpa mengekspos secrets atau sensitive data.

## Usage

Gunakan skill ini ketika perubahan melibatkan logging, metrics, tracing, monitoring, health checks, error reporting, request correlation, operational diagnostics, atau production visibility.

## Steps

1. Analisis execution flow, failure modes, critical operations, existing telemetry, dan informasi yang dibutuhkan untuk memahami behavior system.
2. Implementasikan structured logs, metrics, traces, correlation, health signals, atau error reporting yang relevan dengan context dan hindari sensitive data exposure.
3. Verifikasi telemetry dapat digunakan untuk mendeteksi dan mendiagnosis failure atau performance issue serta tidak menambah noise, excessive overhead, atau security risk.
