# Database

Lakukan perubahan database berdasarkan existing schema, data model, migration system, dan convention yang digunakan project.

Prioritaskan data integrity, backward compatibility, safe migration, dan query correctness. Hindari destructive operation tanpa kebutuhan dan validation yang jelas.

## Usage

Gunakan skill ini ketika perubahan melibatkan schema, migration, model, query, transaction, constraint, index, relation, seed data, atau database performance.

## Steps

1. Analisis existing schema, data model, migration history, constraints, relationships, query patterns, dan impact terhadap existing data serta application behavior.
2. Terapkan perubahan dengan migration yang aman, pertahankan data integrity dan compatibility, serta gunakan transaction, constraint, dan index sesuai kebutuhan aktual.
3. Validasi migration, query correctness, rollback strategy, tests, dan performance yang relevan untuk memastikan perubahan tidak menyebabkan data loss, corruption, regression, atau compatibility issue.
