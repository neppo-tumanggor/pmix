# Enterprise Structure Migration`n`nStruktur folder telah dimigrasi dari SME ke enterprise-grade monorepo.`n`n## Quick Summary`n`n### Yang Berubah:`n- Package Manager: NPM -> PNPM`n- Structure: Single app -> Monorepo (apps/ + packages/)`n- Backend: src/ -> apps/backend/ dengan DDD pattern`n- Frontend: webview/ -> apps/frontend/ dengan route groups`n`n### Scripts Baru:`n```bash`npnpm dev           # Run all apps`npnpm build         # Build all apps`npnpm lint          # Lint all`npnpm test          # Test all`npnpm db:migrate    # Run migrations`npnpm docker:up    # Start services`n````n`n### Environment:`n```bash`ncp apps/backend/.env.example apps/backend/.env`ncp apps/frontend/.env.example apps/frontend/.env.local`ncp .env.example .env`npnpm install`npnpm docker:up`npnpm db:migrate`npnpm dev`n````n`nSee docs/architecture/system-architecture.md for details.
